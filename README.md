# 课程详情与评价参考系统

工程项目认知实践课程项目 —— 从 0 到 1，运用 AI 技术实现选课参考信息模块。

## 项目背景

学校选课阶段仅展示课程名称，缺少课程简介、教师介绍、往期学生评价，导致学生选课预期偏差大。本项目设计并实现一套选课参考信息模块，帮助学生在选课阶段获取完整参考资料。

## 运行方式

### 方式 1：直接打开（推荐）

双击 `选课参考信息模块-高保真原型.html` 即可在浏览器中运行。

右上角可切换 4 种角色体验不同功能：
- 👤 选课学生：浏览课程列表、查看详情、筛选评价
- 🎓 修读学生：提交评价、查看我的评价、举报违规评价
- 👨‍🏫 王雪梅老师：维护课程介绍、回复学生评价、提交教师介绍
- 🛡️ 教务管理员：审核工作台、标签库管理、窗口期配置、代录课程介绍

### 方式 2：本地 HTTP 服务器（可选）

如果遇到浏览器本地文件限制，可用 Python 快速启动：

```bash
python -m http.server 8765
# 然后浏览器访问 http://localhost:8765/选课参考信息模块-高保真原型.html
```

或用 Node.js：

```bash
npx serve .
```

## AI 能力设计

本系统的 AI 辅助能力包括：

1. **AI 课程亮点提取** — 基于课程历史评价自动生成"学生们最常提到的亮点"摘要，帮选课学生快速抓住课程特点
2. **AI 评价合规预审** — 学生提交评价时，AI 自动检测违规内容（代写、包过、联系方式等），减少人工审核压力
3. **AI 个性化推荐** — 根据学生专业和已修课程，推荐可能感兴趣的选修课
4. **AI 学习难度评估** — 基于历史评价关键词（"作业多"/"轻松"/"硬核"）自动给出课程难度标签

原型中已对 AI 评价预审和 AI 亮点提取做了交互模拟（违规词检测、课程亮点卡片）。

## 技术特点

- 纯前端单文件架构，零外部依赖，无需后端即可运行演示
- 完整的评价审核状态机（draft → pending → published / revise / hidden）
- 四维评分 + 标签 + 评语的结构化评价体系
- 多角色权限矩阵（学生/修读学生/教师/教务）
- 举报阈值自动隐藏（3 人举报自动下架，6 人恢复）
- 窗口期开关支持（评教窗口关闭后所有评价只读）

## 待业务决策项（PRD Q1-Q10）

- 适用学段（本科 / 研究生 / 全校）
- 评分可见性（仅已修读学生可见 / 选课阶段可见）
- 评分聚合口径（简单均值 / 加权 / 中位数）
- 评教窗口时长、审核 SLA 等运营参数
